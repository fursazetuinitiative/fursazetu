# FursaZetu Website Information Architecture

Version: 1.0
Status: Active
Website: https://fursazetu.gt.tc



# Purpose

This document defines the structure, navigation, and information architecture of the FursaZetu website.

Its purpose is to ensure visitors can discover relevant opportunities quickly, intuitively, and with minimal effort while allowing the platform to scale as new opportunity types are introduced.



# Design Philosophy

FursaZetu is an **opportunity discovery platform**, not a traditional blog.

The website should be organized around **user intent**, rather than individual opportunity types.

Visitors should think:

> "I want career opportunities."

—not

> "I need to know whether this is an internship, attachment, or graduate programme."



# Primary Website Goal

Enable every visitor to discover relevant opportunities quickly and confidently.

Every page should help users move from discovering an opportunity to applying through the official source.



# Primary Navigation

The main navigation should remain intentionally simple.

- Home
- Browse Opportunities
- About
- Contact

Future additions should only be introduced when they provide significant value and do not increase unnecessary complexity.



# Homepage

The homepage is the platform's opportunity discovery hub.

It should immediately communicate:

- What FursaZetu is.
- What opportunities are available.
- How users can begin searching.

Homepage sections

1. Hero Section
2. Opportunity Search
3. Featured Opportunities
4. Latest Opportunities
5. Browse by Category
6. Why FursaZetu
7. Newsletter
8. Footer

Primary CTA

**Browse Opportunities**

Secondary CTA

**Search Opportunities**



# Browse Opportunities

This is the core of the platform.

It contains every published opportunity.

Users should be able to:

- Search
- Filter
- Sort
- Browse

Filtering should include:

- Category
- Deadline
- Location
- Organization

Additional filters may be introduced as the platform evolves.

# Mobile-First Principle

Most visitors are expected to access FursaZetu using mobile devices.

The entire website should therefore be designed mobile-first, with desktop layouts enhancing rather than defining the experience.



# Scalability

New opportunity types should be added within existing categories whenever appropriate.

New top-level categories should only be introduced when they represent a genuinely different user need.

This keeps navigation clean, intuitive, and sustainable as the platform grows.



# Information Hierarchy

The website should always prioritize:

1. Discover Opportunities
2. Search
3. Browse Categories
4. Build Trust
5. Learn About FursaZetu
6. Contact

Every design decision should reinforce this hierarchy.



# Guiding Principle

Users come to FursaZetu looking for opportunities—not pages.

The website should always minimize the number of clicks between discovering an opportunity and accessing the official application.
