# Purpose

This document defines the Search Engine Optimization (SEO) standards for the FursaZetu platform.

Its objective is to ensure every page is discoverable, accessible, technically sound, and optimized for long-term organic growth without sacrificing usability or content quality.

SEO on FursaZetu is not about manipulating search rankings.

It is about making genuine opportunities easier for people to discover.



# SEO Philosophy

Search engines should understand FursaZetu as clearly as our users do.

Every optimization should improve one or more of the following:

- Discoverability
- Readability
- Accessibility
- Performance
- Authority
- User Experience

Good SEO begins with good content.

Technical optimization exists to help search engines understand that content more effectively.


# Core Principles

## 1. User First

Every SEO decision should improve the experience for users before attempting to improve rankings.

Content should answer real questions, solve real problems, and help users take meaningful action.

If an optimization harms readability or usability, it should not be implemented.



## 2. Quality Over Quantity

Publishing fewer high-quality opportunities is preferable to publishing large volumes of low-quality or duplicated content.

Trust is a long-term SEO strategy.



## 3. Authority Through Accuracy

Every opportunity should link to its official source whenever possible.

Accurate information builds credibility with users and search engines alike.



# URL Structure

URLs should remain:

- Short
- Descriptive
- Permanent
- Human-readable

Example

/funding/mastercard-foundation-scholars-program-2027

Avoid:

- Random numbers
- Dates unless necessary
- Query strings
- Keyword stuffing

URLs should not change after publication unless absolutely necessary.



# Meta Titles

Every page should include a unique title.

Titles should:

- Clearly describe the opportunity
- Include the organization where appropriate
- Remain concise
- Encourage clicks without becoming clickbait

Example

Google Africa Internship Program 2027 | FursaZetu



# Meta Descriptions

Every page should include a unique meta description.

Descriptions should summarize:

- What the opportunity is
- Who it is for
- Why it matters

They should encourage informed clicks rather than exaggerated promises.



# Canonical URLs

Every indexable page should define a canonical URL.

Canonical URLs prevent duplicate content issues and help consolidate search authority.



# Structured Data (Schema.org)

Structured data helps search engines understand page content.

Where appropriate, implement schema for:

- Organization
- Article
- BreadcrumbList
- WebSite
- WebPage
- ImageObject
- Event
- FAQ
- SearchAction

Future versions may include additional opportunity-specific schema as standards evolve.



# Open Graph

Every page should provide Open Graph metadata.

Include:

- Title
- Description
- Image
- URL
- Site Name
- Content Type

Shared links should appear professional across social platforms.



# Twitter Cards

Every page should support Twitter/X Cards.

Include:

- Title
- Description
- Featured Image

Social sharing should preserve the quality and context of the original content.


# Internal Linking Strategy

Every opportunity should connect users to related content.

Internal links should guide users naturally toward:

- Similar opportunities
- Related organizations
- Same hub
- Same opportunity type
- Country-specific opportunities
- Resource pages

Internal links should exist to improve navigation rather than manipulate rankings.



# Keyword Strategy

Keywords should emerge naturally from the opportunity.

Avoid:

- Keyword stuffing
- Forced repetition
- Artificial optimization

Primary keywords should appear naturally in:

- Title
- URL
- Introduction
- Headings
- Meta Title
- Meta Description

Secondary keywords should appear only where relevant.


# XML Sitemap

Maintain an automatically generated XML sitemap containing:

- Active opportunities
- Core pages
- Categories (Hubs)
- Organizations

Archived opportunities may remain indexed where appropriate.



# Robots.txt

Robots directives should:

Allow indexing of:

- Opportunity pages
- Categories
- Organizations
- Guides
- Static pages

Prevent indexing of:

- Administrative pages
- Search result pages
- Temporary pages
- Duplicate content


# Breadcrumbs

Every opportunity should display a clear breadcrumb trail.

Example

Home

↓

Funding

↓

Scholarships

↓

Mastercard Foundation Scholars Program

Breadcrumbs improve both navigation and search visibility.



# Core Web Vitals

Performance is an SEO requirement.

The platform should optimize for:

- Fast loading
- Stable layouts
- Responsive interactions

Heavy plugins, unnecessary scripts, and excessive animations should be avoided.



# Image SEO

Images should:

- Be optimized for web
- Use descriptive filenames
- Include meaningful alt text
- Load responsively
- Be compressed without sacrificing quality

Images should support the content rather than serve as decoration alone.


# Indexing Strategy

Only valuable content should be indexed.

Pages with little or no user value should remain outside search indexes.

Quality should always outweigh quantity.



# Archive Strategy

Expired opportunities should normally remain accessible.

Instead of deleting content:

- Clearly indicate that applications have closed.
- Preserve historical information.
- Link users to current or related opportunities.

Archived content should continue providing value where appropriate.

# Search Console

The platform should integrate with Google Search Console.

Regular monitoring should include:

- Index coverage
- Crawl issues
- Search performance
- Mobile usability
- Structured data validation

Search Console should inform ongoing improvements.



# Analytics

Analytics should measure user success rather than vanity metrics.

Key indicators include:

- Opportunity views
- Click-through rate
- Application link clicks
- Time on page
- Search queries
- Returning visitors
- Internal search behaviour

Data should guide editorial and product decisions.



# Mobile SEO

FursaZetu is designed mobile-first.

Every SEO decision should assume that the majority of users access the platform from mobile devices.

Navigation, readability, speed, and structured content should perform equally well across all screen sizes.


# Future SEO Enhancements

As the platform evolves, additional capabilities may include:

- AI-generated metadata suggestions
- Automatic schema generation
- Intelligent internal linking
- Opportunity recommendation engine
- Search intent analysis
- Semantic content relationships
- Multilingual SEO
- Voice search optimization
- Regional search optimization

Future enhancements should build upon—not replace—the core principles established in this document.

# Guiding Principle

SEO is not the objective.

Helping people discover genuine opportunities is.

Every optimization should strengthen the connection between opportunity seekers and trustworthy opportunities while preserving the integrity, usability, and long-term sustainability of the FursaZetu platform.
