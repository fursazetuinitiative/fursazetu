# Purpose

This document establishes the visual and development principles that guide the design of the FursaZetu website.

It ensures that every page, component, and customization contributes to a consistent, accessible, performant, and professional user experience while preserving the long-term maintainability of the website.


# Design Philosophy

FursaZetu follows a principle of **adaptation over replacement**.

The website is built on the BlogHash/Blogsy WordPress theme, which serves as the project's design foundation rather than a temporary starting point.

Instead of replacing or overriding existing theme functionality, development should focus on refining, extending, and configuring the theme to meet the project's objectives.

Every customization should improve the user experience while preserving the stability, performance, and maintainability of the underlying theme.



# Design Principles

## 1. Theme First

Always use the capabilities provided by the BlogHash/Blogsy theme before introducing custom code or additional plugins.

If a feature already exists within the theme, configure it instead of rebuilding it.



## 2. Purposeful Customization

Every customization must solve a clearly identified problem or improve the user experience.

Avoid custom development simply because it is technically possible.



## 3. Maintainability

Customizations should remain compatible with future theme updates whenever possible.

Avoid modifying theme core files.

Use child themes, WordPress hooks, filters, CSS overrides, or supported extension mechanisms when customization is required.



## 4. Performance First

Performance is a product feature.

Every design decision should preserve:

- Fast page loading
- Low plugin overhead
- Efficient assets
- Optimized images
- Minimal JavaScript
- Minimal CSS

A faster website creates a better user experience.



## 5. Mobile-First Design

The majority of visitors are expected to access FursaZetu using mobile devices.

Every layout, interaction, and component should therefore be designed for mobile first, with desktop enhancements added afterwards.


## 6. Accessibility

Accessibility is a core design requirement, not an optional enhancement.

Pages should remain usable for all visitors through:

- Clear typography
- Logical heading hierarchy
- Keyboard navigation
- Sufficient color contrast
- Responsive layouts
- Descriptive links
- Accessible forms

## 7. Consistency

Consistency builds trust.

Buttons, cards, typography, spacing, forms, icons, and page layouts should behave consistently throughout the website.

Users should never need to relearn the interface from one page to another.



## 8. Simplicity

Every page should communicate one primary objective.

Remove unnecessary visual clutter, duplicate content, and competing calls to action.

Simple interfaces help users focus on opportunities rather than navigation.



## 9. Opportunity-Centered Design

The opportunity is the primary content element of the platform.

Every design decision should make opportunities easier to:

- Discover
- Understand
- Compare
- Apply for
- Share

---

## 10. Progressive Enhancement

The website should function correctly before enhancements are added.

Animations, effects, and advanced interactions should enhance the experience without becoming requirements for usability.


# Development Principle

When making design decisions, always ask:

1. Can the BlogHash/Blogsy theme already achieve this?
2. Can it be configured instead of customized?
3. Can it be extended without replacing core functionality?
4. Will this improve the experience for users?
5. Will this remain easy to maintain in the future?

Only proceed with custom development when the answer to these questions justifies it.



# Guiding Principle

The design of FursaZetu should always prioritize the needs of its users over visual complexity.

Every page, component, and customization should help users discover trusted opportunities quickly, understand them clearly, and access official application sources with confidence.

A simple, fast, accessible, and maintainable website is fundamental to achieving FursaZetu's mission of becoming **Your Curated Link to Growth.**
